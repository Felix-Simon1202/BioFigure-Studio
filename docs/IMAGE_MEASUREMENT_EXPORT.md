# 测量记录下载 1.0

仅成功完成的 `measure_selection` 任务提供附件 JSON 与单行 CSV；缺失记录返回 404，未完成/失败/取消或非测量任务返回 409，不接受其他导出格式。工作台完成任务后显示两个下载入口。近期任务表有界（最多保留 16 项各类近期任务），报告仅随当前会话保留，需及时下载；下载内容不包含原始图像，也不能代替便携图像项目或完整 Fiji 会话恢复。

## JSON

保存原始文件名、字节数、SHA-256、资产 ID 与已检查元数据，完整规范化 ROI（包括多边形顶点）、C/Z/T、真实源轴与所选测量项、创建/结束时间，以及原始 Dataset 统计和 ImageJ1 Analyzer 结果。测量成功时即冻结来源信息，因此随后移除源资产仍可下载已有记录。记录注明原命令 `ij.plugin.filter.Analyzer` 与实际任务使用的固定运行时归档 SHA-256；该摘要来自已审核且执行器必须核验的固定快照，不表示所有快照命令已验证。

候选像素预算 `selection.sample_count` 与真实选中数 `result.sample_count` 分开保留。矩形/全图时相同，椭圆、多边形时可能不同，不把包围盒样本数当作原生形状选中数。原生未请求的测量字段保持缺失，不生成默认零值。

## CSV

UTF-8 BOM、标准 CSV 引号，单行保留来源摘要、索引、ROI/源轴 JSON 单元格、候选数/实际数、原始统计、原生面积及单位、可选原生测量项和运行时摘要。未请求的项为空。数字直接保留后端结果精度，不按界面显示舍入；JSON 为完整结果，CSV 只列出已支持的规范列。

所有文本单元格在前导空白后以 `= + - @` 开头时添加文字前缀，避免文件名或源图单位被表格软件当公式执行；负数统计仍以数值导出。精确未转义文件名和单位始终留在 JSON 中。没有根据输出数值添加统计结论。

## 代码与验证

任务管理器在锁内确认任务成功并复制快照；纯格式模块处理 JSON/CSV，HTTP 层只返回具有明确附件文件名的响应。工作台测量结果拆为独立显示组件，避免继续扩大内联长表单。

受控结果测试验证了形状候选 35/实际 31、负数统计、缺失选项、中文与逗号/引号文件名、CSV 公式前缀、源图移除后来源保留、快照不能反向修改任务以及拒绝下载未完成结果。该测试的引擎桩不计真实 Fiji 证据。原生椭圆与多边形的固定引擎专项另对真实结果、来源 SHA 和下载 JSON/CSV 逐字段核对；本分支实际运行结果在 TASKS 中单独记录。
