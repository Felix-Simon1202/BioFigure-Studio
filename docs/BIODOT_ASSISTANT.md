# Biodot drawing assistant

Biodot is the product's warm, concise scientific-drawing assistant identity,
independent of the configured model. English and Simplified Chinese greetings
use the same interface-language preference. Settings retain the true provider
and model. Simple greetings/help are handled locally without a model request.

The shared persona block is included in local drawing proposals, fixed
synthetic workflow extraction, and configured external chart requests.
Drawing proceeds through clarify → propose → review → execute → verify.
The existing structured schemas, readiness checks, admission lock, explicit
confirmation, and external synthetic-prompt consent remain in force.

The capability API includes Biodot's identity and actual connector-tool
readiness. Current in-app model proposals remain synthetic scatter/line
charts and built-in TIFF inspection. Paired HTTP/MCP clients can discover
the existing reviewed chart, figure, project, R, vector and Fiji tools.
The unreleased source update also exposes selected-illustration edit proposals:
color, label, move, alignment and display size. Exact local commands or the existing
reviewed local model produce typed changes for explicit user confirmation. No
unselected object is edited and verified objects remain protected. See
FIGURE_WORKFLOW_DELIVERY.md for this bounded source delivery and its evidence.
This version does not enable arbitrary shell execution, unrestricted software
control, free-form cloud research uploads, or claim every editor is automated.

## DeepTutor design reuse

The reviewed Apache-2.0 source separates the persona's voice from capability
playbooks and injects the active persona into the system context. Biodot
adapts that small framing block, uses an approachable peer voice and evidence
discipline, and supplies a drawing-specific playbook. Source paths, pinned
commit, hashes, license and modification notes are in licenses/DeepTutor.

## English examples and preserved content

Built-in example factories create English titles, steps and timeline fields
when chosen in English mode. UI-authored placeholders and model-demo prompts
also follow the selected language. Fixed timeline axis/sample labels and
mechanism relation labels use the same locale on canvas and SVG/PNG export.
User-supplied titles, labels, filenames, source paragraphs and open projects
are not rewritten when switching language. Existing scientific IDs, geometry,
evidence and raw data stay unchanged. The bilingual spotlight is untouched.
