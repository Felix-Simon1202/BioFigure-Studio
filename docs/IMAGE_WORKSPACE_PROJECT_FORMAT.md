# 图像工作台项目格式 1.0（核心、异步恢复及网页往返已实现）

本格式用于保存原始图像/组合栈、已支持的命名 ROI 集合与当前选择。它与单张原像素网格的 `exact_pixel_grid` 项目分别识别，`kind` 为 `image_workspace`。不会把多页栈扁平化或转成显示 PNG。

已实现读写核心、跨端格式冻结及 `POST /api/image/jobs/open-workspace` 异步恢复接口，逐源经固定 Fiji 重新检查后恢复原始栈和已支持状态；网页已提供“保存工作台项目”和 `.bfswork` 打开入口；当前已支持字段的实际网页往返证据见下节。成品旁“保存项目包”保存单张网格格式；资源区“保存工作台项目”保存原始栈与已支持状态，不能据此宣称全部 Fiji 状态已可重开。

## 内容与边界

- 1 至 8 份原始源文件，单份不超过 1 GiB，总量不超过 2 GiB，字节及 SHA-256 原样保留。
- 固定 ZIP_STORED 条目 `project.json` 与 `sources/0.bin` 等；清单上限 1 MiB。来源键固定为 s0…s7，归档路径不控制提取路径。
- `source_states` 按来源键保存可选的命名集合和当前选择。集合复用既有 128 KiB / 64 ROI 来源绑定契约；选择保留 C/Z/T、矩形/椭圆/多边形或全图、已支持的原生测量选项。
- `active_source_key`、有序 `selected_source_keys` 及列数/间距保留当前工作台选择与网格设置，拒绝不存在或重复来源。
- 不保存任意命令、脚本、服务器路径或新的执行权限。其他 Fiji 工具参数、测量历史、视图缩放等尚未进入此格式，后续按完整目标扩展，不能把当前字段当成整套状态完成。

外层及选择对象严格拒绝未知字段；来源元数据仅为 recorded_metadata 声明。ROI/集合在保存时对实际来源重新校验，当前选择重新计算规范几何和测量选项，不保存伪造的派生像素数。集合依赖的源轴必须来自当前已检查资产；没有编辑状态的原始源图可作为未检查输入保存。

规范模型为 `backend/image/workspace_project.py`，跨端 JSON Schema 固定于 `docs/schemas/image-workspace-project-1.0.schema.json`。清单中只保存稳定来源键，当前会话 asset ID 转成 sN；ROI 的稳定条目 ID、名称、几何和每项轴位置保留。

## 与网格项目共用归档实现

原始源列表、ZIP 成员/尺寸/摘要校验、严格目录提取、独占创建和取消检查共用 `backend/image/project.py`。网格格式字段和原有入口保持兼容，读取函数按指定模型校验，不能用网格入口误开工作台包。每份复制按声明源长度提前截止，源图变大时不会一直写到全局文件上限才报错。失败仅清理本次创建的文件，既有输出和目标目录不覆盖。

读取结果始终是 `PendingImageProject(verification_status=requires_fresh_inspection)`，不创建已验证资产、不运行测量、不恢复 UI。应用层 `workspace_import.py` 已逐源调用固定 Fiji 检查器，再用实际新元数据重新校验集合/当前选择，重绑定新 asset ID，并在完整成功后一次发布资产与工作台状态；任一失败撤回本次输入和预约。不能将记录轴直接传作新验证结果。

## 实际核心测试

8 项新工作台核心用例，连同原网格项目、事务重开、下载及磁盘专项共 32 passed / 1 runtime skipped。合成 2×3×2 TIFF 的 12 页及 RGBA 隐藏 RGB 原始字节保留，命名 ROI、C/Z/T、测量选项、当前/选中来源顺序和列数间距往返。错误来源键、越界轴、浮点几何、未知字段、错误摘要拒绝且不创建包；取消和已有输出保留；修改记录标定只得到 pending 声明，不改变当前资产。

上述 32 项是当时的包核心测试，不单独支持真实引擎重开、网页往返、所有科研格式或崩溃恢复结论。后续异步恢复与真实引擎证据见下节；完整状态和用户验收仍待办。


## 异步原始栈恢复与实际 Fiji 证据

`POST /api/image/jobs/open-workspace` 复用统一任务准入、租约、队列关闭与取消流程；项目/批量上传共用解析前限量准入和磁盘预检。仅完整核验后，在管理器锁与资产事务内绑定新来源 ID、当前来源、有序选择、ROI 集合、C/Z/T/额外测量及网格参数。恢复原始栈不生成扁平化网格，也不占用拼版成品名额。现有网格项目接口复用同一原图检查函数，减少重复代码；独立读取格式仍严格区分。

合成项目覆盖全量成功、第二来源检查失败、实际轴改变、容量不足、取消及发布回调拒绝，均核对资产/状态不部分出现、暂存文件与预约释放。HTTP 专项验证正在处理时另一个项目上传返回 429、取消后可重试、成功后的取消为无操作；成品容量设为零仍可恢复原始栈。

另显式使用已审核固定 Fiji，真实检查并打包 2×3×2 TIFF，重开后再次真实检查，再对恢复的 C=1/Z=2/T=1 椭圆执行原生测量：31 像素、31 µm²、均值 11031；原始 TIFF 全字节一致，12 页、轴信息与 ROI 名称保留（专项 1 passed，17.26 秒）。该核心专项本身不是网页证据；后续实际浏览器证据见下节。完整工具状态、编辑历史和其余 Fiji 功能仍待接通。

异步恢复整合后，工作区/网格项目、统一提交、上传准入和磁盘专项合计 72 passed / 2 runtime skipped（1.82 秒）；真实工作区重开专项另行显式执行通过。


## 网页保存、恢复与下载证据

网页新增“保存工作台项目”，把所有会话原始来源、按来源保存的命名 ROI、当前活动图像及其有效选择/额外测量、选中来源顺序与网格参数保存。当时网页只采集活动图像的当前选择，后续按来源保存和恢复的补齐证据见下节；命名 ROI 已按来源保存。`.bfsimg` 与 `.bfswork` 按扩展名进入各自严格读取接口。重开成功自动恢复当前选择，并允许从近期成功任务“恢复此项目状态”；已移除来源的旧任务不能恢复。首次载入页面不会用历史任务静默覆盖正在编辑的状态。

保存使用限量本机表单及原生附件下载，浏览器不把整个大项目转换成 JavaScript Blob；错误在新标签页显示。目前保存准备本身不是可见队列任务，网页没有保存进度及取消按钮，这仍属待完善交互。保存与网格导出共用一份准入、来源租约、磁盘预检和下载完成后的清理，减少归档代码重复；请求取消时，后台任务仍拥有资源，完成后清理无人接收的输出。新增测试覆盖表单字段上限、错误来源、源字节及状态、下载后清理和取消请求后无人接收响应的清理。

真实浏览器使用合成 `combined-czt16.tif`：固定 Fiji 检查后在 C=1/Z=2/T=1 创建 x=1/y=1/width=7/height=5 椭圆，加入 `Workspace nucleus`，启用标准差，实际保存下载为 5870 字节 `.bfswork`。包 SHA-256 为 e25c939ff63a1ef10ef047a6bfd3acf105df7ab6e81f7cd8debab15dacfbb7a8；其中源图与原始文件逐字节一致，SHA-256 为 fb7aaf7345b5170a4192e97bc7ea9a230cb0ab70f1d1d5c788593045287fd018。移除会话源图，再从下载文件打开，固定 Fiji 重新检查后恢复命名条目、当前平面、形状/尺寸、标准差和选中来源。再改 C=0 并关闭 ROI，点击恢复状态，控件回到 C=1/Z=2/T=1 椭圆；再次实际测量及下载 JSON 返回 31 像素、31 µm²、均值 14564、标准差 26.897335679703794，来源摘要与保存包一致。

浏览器附件已实际落盘；新标签页附件不会由原页的下载事件捕获，因此测试读取本次已知文件名对应的下载，而没有把事件超时当成下载失败或成功。保留截图 `work/workspace-browser/restored.png`、下载包、清单证据与测量 JSON。测试仅使用合成图像；没有上传真实科研数据。浏览器中运行状态清单仍指向主工作树路径，故显示未就绪；本轮执行器显式指向已审核的独立工作树运行时，此环境差异不作为正式安装完成证据。


## 各来源的独立编辑状态

网页的 C/Z/T、ROI 启用、形状、矩形参数、多边形编辑文本及额外测量选项已集中到 `measurementEditor.ts`，按会话资产 ID 保存，不按像素摘要合并。切换已检查图像时不再重置一组全局字段；保存工作台项目时包含所有已有来源草稿的有效选择，恢复时一次按新资产 ID 应用全部选择。移除源图时同步清理编辑草稿和命名集合，避免反复导入/移除积累状态。无效多边形草稿仍可在图像间切换保留，但保存时明确要求修正，不静默将其变为全图。

真实浏览器使用同一合成 2×3×2 TIFF 的两个独立资产（文件名不同、字节与 SHA 相同）验证资源隔离：第一份 C=1/Z=2/T=1、7×5 椭圆/标准差；第二份 C=0/Z=1/T=0、3×2 矩形/中位数。切回第一份时其值恢复；实际下载 10380 B 项目包，清单 s0/s1 各自保留上述不同选择，两个原图条目逐字节一致。移除两份会话资产并从该下载包重新打开，经固定 Fiji 逐源检查后，第一份与此前非活动的第二份均在切换时恢复各自值。截图 `work/workspace-browser/two-source-restored.png`；前端构建、lint、空会话 SSR 回归通过。此轮只变更前端编辑状态，不重复声称完整引擎或工具集验收。

## 1.1 原生测量状态

新保存的 `.bfswork` 使用 1.1，当前读取器仍支持 1.0。每个来源可带 `native_measurement`，包含规范化的测量项、精度、阈值、独立原生区域，以及可选第二来源和其 C/Z/T。区域为 null 时沿用同一来源的普通工作台选择。归档使用稳定的 sN 键，重开先校验实际轴和区域，再把第二来源与主来源一起映射为新会话资产 ID。旧包的该字段缺省，使用默认测量参数。参见 `docs/schemas/image-workspace-project-1.1.schema.json` 和 `docs/IMAGE_WORKSPACE_ACCEPTANCE_20261108.md`。
