## Changes / 更新内容

- Default Biodot conversation home and sliding switch to the original spotlight
  local home, with compact hover/click/touch/keyboard task groups.
- 25 scientific palettes, original 28-component cell-biology vector library,
  shared editor/export geometry and contained illustration wheel scrolling.
- Reviewed four-panel style mapping and selected-object Biodot edits, including
  confirmation, stale-preview protection and undo.
- Persistent presentation queue, exact source copies/manifests, isolated failures,
  retry, restart recovery and individual/organized archive downloads.
- Native downloads now admit actual local project, ZIP and TIFF formats while
  rejecting remote origins and executable extensions. Filter labels use neutral
  format names. The original spotlight art, pointer effect and bilingual copy stay.

## Limits / 验证边界

This is a checked candidate, not user acceptance. The installer remains unsigned.
The prior clean Windows 10 no-WebView2 offline-install matrix was not repeated for
this new package/runtime; Windows 11 clean first install, upgrades and whole-system
network silence are not newly verified. The tests launch extracted payloads without
replacing an existing user installation or changing system settings.

Fiji, R and models require separate supported setup. Packaged engine networking stays
loopback-only; AI home startup makes no inference request. The image queue unifies
presentation around images, not measured pixel content or embedded labels. Current
format/capacity limits are in FIGURE_WORKFLOW_DELIVERY.md. Release attachment upload
and user acceptance are separate actions.
